# Event Feedback Management System 🚀

A full-stack web application that allows Event Managers to create events and attendees to provide feedback with emoji ratings and sentiment tags. 

### 🌐 Live Demo
**[Click here to view the Live Project](https://feedback-management-system-91n3.onrender.com/)**

---

### ✨ Key Features
* **Role-Based Access Control:** Separate portals for Admin, Event Managers, and regular attendees.
* **Interactive Feedback:** Emoji-based rating system with automated sentiment tagging (Positive, Neutral, Needs Attention).
* **Analytics Dashboard:** Live chart-like visualization of feedback sentiments for managers.
* **Responsive UI:** Glassmorphism design that works seamlessly on desktop and mobile.

### 🛠️ Technologies Used
* **Frontend:** HTML5, CSS3 (Glassmorphism), Vanilla JavaScript
* **Backend:** Node.js, Express.js
* **Database:** SQLite (Relational Database)
* **Deployment:** Hosted on Render

1. Clone this repository:

2. Install the required dependencies:

npm install

3. Start the local server:

node server.js

4. Open your browser and go to: http://localhost:3000
